# RIFT MAC Gen

A fast and lightweight MAC address generator for creating random and customizable MAC addresses.

## Features

- 📡 Generate Random MAC Addresses
- ⚙️ Custom MAC Address Generation
- 🔢 Valid MAC Format Support
- ⚡ Fast & Lightweight
- 📋 Easy Copy Function
- 🧪 Useful for Testing & Development
- 💻 Simple Interface
